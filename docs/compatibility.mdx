## Behavior kept identical

- No `OK` until the event is durably committed.
- Tag indexing: single-letter names, first value, values up to 255 bytes. `e` and `p` values must be 64 lowercase hex.
- Replaceable and addressable resolution: newer `created_at` wins, and on a tie the lower id wins.
- Write-policy plugin protocol: line-delimited JSON on stdin and stdout, the same input fields, and `accept`, `reject`, and `shadowReject` actions. Existing strfry plugins work unchanged.
- Prometheus metric names: `nostr_client_messages_total`, `nostr_relay_messages_total`, `nostr_events_total`.
- CLI verbs: `relay`, `import`, `export`, `scan`, `delete`, `compact`, `sync`.

## Deliberate deviations

| Topic                       | strfry                                      | nkr                                        | Reason                                                                                                                                          |
| --------------------------- | ------------------------------------------- | ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Ephemeral events            | stored for 5 minutes, then deleted          | never stored, broadcast directly           | NIP-01 says they are not stored; strfry stores them only because of its inotify design ([ADR 0005](/decisions/0005-sequence-snapshot-delivery)) |
| Superseded replaceable `OK` | `false`, `replaced: have newer event`       | `false`, `duplicate: have a newer version` | `replaced` is not one of the standard NIP-01 prefixes                                                                                           |
| Deleted event re-published  | `false`, `deleted: user requested deletion` | `false`, `blocked: deleted by its author`  | `deleted` is not a standard prefix                                                                                                              |
| Empty filter lists          | depends on version                          | match nothing                              | NIP-01 MUST                                                                                                                                     |
| Hex prefix filters          | older versions accepted them                | rejected                                   | removed from NIP-01                                                                                                                             |
| Unknown filter keys         | ignored                                     | `CLOSED` with `unsupported:`               | NIP-01 example behavior; silently widening a query is worse than refusing it                                                                    |
| Configuration format        | taocpp config                               | TOML, same tree and defaults               | idiomatic for Rust tooling; conversion is mechanical                                                                                            |
| Database format             | LMDB with golpe schema                      | nkr's own schema                           | migrate with `strfry export` piped into `nkr import`                                                                                            |
